# 发哥数字工坊 | Fage AI Workshop
> A ComfyUI AICG project with custom nodes, ready-to-use workflows and model configs

## ✨ 项目介绍
面向ComfyUI生态的AICG个人实践仓库。
项目包含自研扩展节点、开箱即用的图像生成工作流、模型配置清单与调参方案，专注AI绘画流水线定制、效果优化与落地实践。

## 📦 项目内容
- **custom_nodes 自定义扩展节点**：补充ComfyUI原生缺少的批量处理、图像预处理、参数转换等实用节点
- **workflows 工作流**：多套可直接导入的JSON工作流，覆盖文生图、图生图、高清修复、风格迁移，附带预览图
- **models 模型资料**：整理Checkpoint、LoRA、ControlNet等模型的下载地址、推荐参数与部署路径（**仓库不存放模型权重文件**）
- **outputs 作品样例**：工作流生成效果图预览
- **docs 使用文档**：节点安装、工作流导入、模型部署、常见问题排查

## 🧰 环境要求
- ComfyUI
- Python >= 3.12
- 依赖包：参考 `requirements.txt`
